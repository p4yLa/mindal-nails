# Ногтевой кабинет «Миндаль» — демо-сайт

![Главная страница на компьютере и телефоне](img/readme-screen.webp)

**Сайт:** https://p4yla.github.io/mindal-nails/ (адрес будущей публикации)

Одностраничный сайт частного мастера маникюра и педикюра, которая принимает клиенток у себя дома в Митино. Главная задача сайта — клиентка сама записывается в свободное окно, а мастеру приходит сообщение в Telegram.

Демо-проект для портфолио. Мастер, телефон, адрес, отзывы и рейтинг вымышлены.
Разработка: Анисимов П.Э., Telegram [@p4yLa](https://t.me/p4yLa).

## Что умеет сайт

- **Запись без переписки.** Клиентка выбирает услуги, видит настоящие свободные окна мастера и записывается за минуту. Писать «а есть что-нибудь в четверг?» не нужно.
- **Окна считаются честно.** Маникюр + педикюр + дизайн занимают 3 ч 30 мин, и сайт покажет только то время, куда всё это помещается целиком. Учтены рабочие дни, обед и 15 минут на дезинфекцию между клиентками.
- **Двойной записи не будет.** Если две клиентки нажмут «Записаться» на одно время одновременно, пройдёт только одна. Вторая увидит обновлённое расписание.
- **Адрес квартиры не висит в интернете.** На сайте только район и метро. Точный адрес, подъезд, этаж и код домофона клиентка видит после записи: на экране подтверждения и в файле для календаря.
- **Напоминания в календаре.** Кнопка «Добавить в календарь» сохраняет визит с адресом и двумя напоминаниями: за день и за 2 часа.
- **Мастеру — сообщение в Telegram.** Услуги, время, сумма, имя, телефон и как клиентке удобнее получить подтверждение.
- **Правила без воды.** Отмена и перенос, опоздание, стерильность инструментов, кошка в квартире — до записи, чтобы потом не было сюрпризов.
- **Работает на телефоне и для всех.** Вёрстка от телефона, крупные кнопки, проверка формы на лету, доступность для экранных читалок.

## Почему адрес только после записи

Это главная боль домашних мастеров. Если адрес квартиры опубликован, его видит кто угодно: случайные люди приходят «посмотреть», соседи жалуются, а мастер работает одна. Поэтому:

- в HTML, JSON-LD и на карте только район «Митино» и метро; на заглушке карты — область, а не точка дома;
- в рабочем режиме адрес хранится **в секретах Cloudflare** (`ADDRESS`, `ADDRESS_NOTE`), а не в коде. Сервер отдаёт его только в ответе на успешную запись. Его нет ни в исходниках сайта, ни в публичном репозитории;
- в демо-режиме (без сервера) показывается вымышленный адрес из `DEMO_ADDRESS` в `js/main.js`. При подключении воркера этот объект можно удалить.

## Стек

Чистые HTML, CSS и JavaScript, без фреймворков и сборщиков. Сайт открывается двойным кликом по `index.html`.

```
index.html      главная: все секции, SEO, JSON-LD (NailSalon, без точного адреса)
privacy.html    политика обработки ПДн (шаблон)
404.html        страница «не найдено»
css/style.css   переменные в начале файла, дальше mobile-first
js/schedule.js  правила расписания — ОДИН файл для сайта и для сервера
js/main.js      меню, галерея, запись, маска телефона, .ics, cookie
img/            фото WebP, og.jpg, favicon.svg, readme-screen.webp
fonts/          cormorant.woff2, cormorant-italic.woff2, manrope.woff2 (62 КБ на все три)
netlify.toml    на случай переезда на Netlify
worker/         Cloudflare Worker: свободные окна (D1), запись, сообщение в Telegram
robots.txt, sitemap.xml
```

## Расписание и запись

```
сайт (GitHub Pages)
   │  GET /slots?services=mani_gel,ex_design   — свободные окна на 21 день
   │  POST /  { type: 'booking', ... }          — запись; в ответе адрес
   ▼
Cloudflare Worker  mindal-booking               (worker/index.js)
   ├─ правила расписания: ../js/schedule.js     (тот же файл, что на сайте)
   ├─► Cloudflare D1 «mindal» — таблица bookings (worker/schema.sql)
   └─► Telegram-бот → личный чат мастера
```

**Правила мастера** лежат в начале `js/schedule.js`: рабочие дни (вт–сб), часы (10:00–20:00), обед (14:00–15:00), шаг окон (30 мин), дезинфекция после клиентки (15 мин), запись на 21 день вперёд, на сегодня — не позже чем за 2 часа, праздники и отпуск (`DAYS_OFF`). Этот же файл подключает воркер, поэтому сайт и сервер не могут разойтись в правилах.

**Как считается окно.** Процедуры `[начало, начало + длительность)` должны уложиться в рабочие часы и не задеть обед. Вместе с 15 минутами на дезинфекцию они не должны пересекаться ни с одной записью, у которой тоже учитываются её 15 минут. Пример: запись 10:00–12:00 занимает мастера до 12:15, поэтому следующее окно начинается в 12:30.

**Услуги и цена.** В группах «Маникюр» и «Педикюр» можно выбрать по одной услуге, дополнения — только вместе с ними. За маникюр и педикюр в один визит скидка 300 ₽. Сайт отправляет только коды услуг: длительность, скидку и сумму сервер считает сам, потому что сумму в запросе легко подменить.

**Защита от двойной записи.** Запись сохраняется одним SQL-запросом `INSERT ... WHERE NOT EXISTS (пересечение с учётом 15 минут)`. SQLite выполняет его атомарно, поэтому из двух одновременных запросов на одно время пройдёт только один. Второй получит 409, и сайт вернёт клиентку к выбору времени с обновлённым расписанием.

**Демо-занятость.** В новой базе записей нет, а пустой календарь выглядит неправдоподобно. Поэтому в каждом рабочем дне «записаны» 1–3 вымышленные клиентки (детерминированно, по хешу даты). Реальные записи ложатся поверх. Для настоящего мастера поставьте `DEMO_BUSY = false` в `js/schedule.js`.

**Секреты** (токен бота, ID чата, адрес) хранятся только в Cloudflare. Функция пускает заявки только с домена сайта (`ALLOWED_ORIGINS`), отсеивает спам-ботов полем-ловушкой и принимает не больше 5 заявок с одного IP за 10 минут. Если отправка не удалась, клиентка видит ошибку с телефоном мастера, а не ложный экран успеха.

**Подключено.** Воркер работает: https://mindal-booking.p4yla.workers.dev (адрес вписан в `LEAD_ENDPOINT` в `js/main.js`). Это по-прежнему демо-сайт, но запись уходит по-настоящему: сохраняется в D1 и приходит разработчику в Telegram. Об этом честно сказано на сайте рядом с кнопкой отправки. В ответе воркера поле `notified` показывает, дошло ли сообщение до Telegram. Если вернуть в `LEAD_ENDPOINT` пустую строку — офлайн-демо: окна считаются в браузере, запись никуда не уходит. Секреты `ADDRESS` и `ADDRESS_NOTE` сейчас содержат тот же вымышленный демо-адрес, что и `DEMO_ADDRESS`.

### Команды

```
cd worker
npx wrangler d1 create mindal                                    # создать базу, id вставить в wrangler.toml
npx wrangler d1 execute mindal --remote --file=schema.sql        # создать таблицу
npx wrangler secret put BOT_TOKEN                                # токен от @BotFather
npx wrangler secret put CHAT_ID                                  # ID чата мастера
npx wrangler secret put ADDRESS                                  # «Москва, ул. ..., д. ..., кв. ...»
npx wrangler secret put ADDRESS_NOTE                             # «Подъезд 3, этаж 9, домофон 112»
npx wrangler deploy                                              # выложить функцию
npx wrangler d1 execute mindal --remote --command "SELECT * FROM bookings ORDER BY id DESC LIMIT 20"
```

Отменить запись (окно снова станет свободным):
`npx wrangler d1 execute mindal --remote --command "UPDATE bookings SET status='cancelled' WHERE id=12"`

## Перед запуском настоящего сайта

- Подключите свой бот и чат мастера (`wrangler secret put BOT_TOKEN` / `CHAT_ID`), задайте настоящий адрес в секретах `ADDRESS` / `ADDRESS_NOTE`, удалите `DEMO_ADDRESS` и пометку `.demo-note` у формы.
- В `js/schedule.js` поставьте `DEMO_BUSY = false`, проверьте рабочие дни, часы, `DAYS_OFF` и цены. Цены в таблице на сайте (`data-price`) должны совпадать с `SERVICES`.
- Сейчас canonical, og:url, og:image, robots.txt и sitemap.xml указывают на `https://p4yla.github.io/mindal-nails/`. При переезде на свой домен замените их, в 404.html уберите `<base href="/mindal-nails/">`, а новый домен добавьте в `ALLOWED_ORIGINS` в `worker/index.js`.
- Раскомментируйте Метрику и Вебмастер в `<head>` и вставьте свои коды.
- Проставьте реальные ссылки на Telegram, WhatsApp и ВКонтакте (сейчас `#`), телефон, ИНН и текст политики, согласованный с юристом.
- Замените фото работ на настоящие работы мастера.

## Шрифты

Cormorant (заголовки) и Manrope (текст), лицензия SIL Open Font License, взяты из репозитория [google/fonts](https://github.com/google/fonts):

- `cormorant.woff2` — толщина 600, 20 КБ;
- `cormorant-italic.woff2` — курсив 500 для акцентных слов, 20 КБ;
- `manrope.woff2` — вариативный 400–700, 22 КБ.

В файлах оставлены латиница, кириллица, цифры и знаки «» — № ₽ × °, а из OpenType-функций — только кернинг, лигатуры и цифры. У Cormorant по умолчанию «старинные» цифры разной высоты: в цене «2 600 ₽» они прыгают. Поэтому при сборке цифры переназначены на ровные (lining), без CSS-хитростей. Если на сайте появится символ, которого нет в шрифте, браузер подставит системный. Пересобрать — пакетом [subset-font](https://www.npmjs.com/package/subset-font):

```js
import subsetFont from 'subset-font';
const woff2 = await subsetFont(fs.readFileSync('Cormorant[wght].ttf'), text, {
  targetFormat: 'woff2',
  variationAxes: { wght: 600 },
  keepFeatures: ['kern', 'liga', 'calt', 'ccmp', 'locl', 'mark', 'mkmk', 'lnum', 'tnum']
});
```

## Проверки

**Логика расписания и воркер** — проверочный скрипт на Node 24: воркер запускался с настоящим SQLite (`node:sqlite`) вместо D1. 299 проверок, все пройдены: рабочие дни и праздники, обед, закрытие, дезинфекция до и после записи, запись на сегодня не раньше чем через 2 часа, демо-занятость без пересечений, сумма и скидка считаются на сервере, повторная и одновременная запись на то же время → 409, атомарность самого SQL-запроса, CORS, ловушка, лимит по IP, адрес не отдаётся без секрета.
